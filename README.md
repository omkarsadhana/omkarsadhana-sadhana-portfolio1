# Pixels by Omkarsadhana

A cinematic full-stack portfolio for Sadhana Prakash Omkar.

## Frontend

```bash
npm install
npm run dev
```

## Backend

```bash
cd backend
mvn spring-boot:run
```

Routes: /, /works, /gallery, /resume.

Add the real resume at `public/assets/resume.pdf` and gallery media under `assets/gallery/`.
